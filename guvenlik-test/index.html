Hedef Bilgileri

Çalışma Prensibi

Sunucu hedef IP'ye SMB (445) üzerinden bağlanır, WMI ile mshta.exe çağrısı yaparak yerel MessageBox açtırır. Hedef makinede hiçbir ajan, paket veya port açma gerekmez — Windows'un kendi mekanizmaları kullanılır.

  • Hedef gereksinimi: Windows 7/10/11, hesap parolası ile erişim
  • Açık port: 445 (SMB) — varsayılan olarak aktif
  • Yetki: Hedefte yerel Administrator veya domain admin hesabı

Hakkında

SecPanel — yetkili güvenlik testleri için geliştirilmiş port tarama ve açık tespiti aracı.

Nasıl Kullanılır?

  • IP Tarayıcı sayfasına gidin.
  • Test makinenizin IPv4 adresini girin (örn: 192.168.1.100).
  • "Tara" butonuna basın — 15 port paralel taranır.
  • Uyarılar kritik / uyarı / bilgi seviyelerinde gösterilir.
  • Sonuçlar otomatik olarak geçmiş sayfasına kaydedilir.
